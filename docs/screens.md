# Screens and controls

- **Main** — SOC, pack voltage, power/current, cell maximum/minimum/delta and maximum temperature.
- **Cell Monitor** — all 96 cell voltages with min/max cell markers and temperature range.
- **Events** — wrapped event text with severity colours.
- **Battery Info** — contactors, closing permission, SOH, real SOC, limits, HVIL, BMS state and isolation.
- **Web Control** — navigation and guarded Battery Emulator controls in Wi-Fi mode.
- **System** — firmware, connection, radio, data age and uptime diagnostics.
- **DTC/Faults** — fault list and hold-to-confirm maintenance commands in Wi-Fi mode.

Swipe between pages. The orientation button cycles all four rotations and applies the matching touch transform.
