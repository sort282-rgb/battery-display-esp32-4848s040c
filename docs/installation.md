# Installation

Use Chrome or Edge on a computer and a USB data cable. The installer accepts only the USB bridge used by the ESP32-4848S040C-I and verifies ESP32-S3 before flashing.

- Choose **Update** to keep connection, orientation and display settings.
- Choose **Factory install** for a new board or a complete recovery. This erases all saved settings.

Do not disconnect power while flashing. After a factory install, complete connection setup on the touch screen or connect to the `BatteryEmulator-CYD` setup network and open `http://192.168.4.1`.
